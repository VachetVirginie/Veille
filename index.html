100 % gratuit · open source · sans tracking

Votre veille, sans abonnement.

Configurez des flux RSS et des mots-clés. Le worker GitHub Actions vérifiera les nouveautés toutes les heures et les transmettra à Telegram ou Discord.

Sources RSS

Exemple : Vue.js | https://blog.vuejs.org/feed.rss

Filtrage

Une alerte est envoyée si le titre ou le résumé contient au moins un mot-clé.

Notifications

Les secrets restent dans GitHub Actions, jamais dans cette page.
